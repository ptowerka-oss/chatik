# Чатик — мессенджер для двоих

Регистрация по логину и паролю, у каждого свой ID, поиск друга по ID, сообщения в реальном времени,
свои стикеры, фото, темы оформления. Приложение для Android (APK) + маленький сервер.

```
www/      — само приложение (то, что внутри APK; также открывается в браузере)
server/   — сервер (Node.js, без установки пакетов)
.github/  — автосборка APK на GitHub
```

## Как получить APK (≈20 минут, всё бесплатно)

### Шаг 1. Выложить проект на GitHub
1. Зарегистрируйтесь на github.com → **New repository** → имя `chatik` → **Create**.
2. **uploading an existing file** → перетащите всё содержимое папки проекта (включая папку `.github`) → **Commit changes**.
   *Если папка `.github` не загрузилась:* **Add file → Create new file**, имя `.github/workflows/build-apk.yml`, вставьте туда содержимое файла из архива.

### Шаг 2. Запустить сервер (чтобы люди могли общаться)
1. Зарегистрируйтесь на render.com через GitHub.
2. **New → Blueprint** → выберите репозиторий `chatik` → **Apply**.
3. Через пару минут появится адрес вида `https://chatik-xxxx.onrender.com`. Откройте его — должно загрузиться приложение. **Скопируйте адрес.**

### Шаг 3. Сказать сборщику адрес сервера
В репозитории: **Settings → Secrets and variables → Actions → Variables → New repository variable**
Имя: `SERVER_URL`, значение: адрес из шага 2 → **Add variable**.

### Шаг 4. Собрать APK
**Actions → Build APK → Run workflow**. Через ~5–8 минут: вкладка **Releases** (справа на главной странице репозитория) → скачайте **Chatik.apk**
(или в самом запуске, внизу, раздел Artifacts). Установите на телефон (разрешите установку из неизвестных источников).
Тот же файл отправьте второму человеку. Пересобирать при каждом изменении не нужно — только если меняете приложение.

## Важно про сервер
* **Бесплатный Render «засыпает»** через 15 минут без активности (первый вход после сна ждёт до минуты) и
  **стирает файлы при перезапуске**: аккаунты и переписка пропадут. Для проверки подходит, для постоянной работы — нет.
* Чтобы данные сохранялись: в Render у сервиса выберите платный тариф Starter (≈7 $/мес), добавьте **Disk**
  (Mount path `/var/data`) и переменную окружения `DATA_DIR=/var/data`.
* Или запустите сервер на своём компьютере / VPS: `node server/index.js` (нужен Node.js 18+, порт 3000, переменная `PORT`).
  Для доступа из интернета нужен https-адрес (например, через Cloudflare Tunnel).

## Что умеет
* Регистрация: логин + пароль + повтор пароля. Вход: логин + пароль.
* Каждому выдаётся 7-значный ID (виден в списке чатов и в настройках). Поиск человека — по ID.
* Текст, эмодзи, фото, стикеры; галочки «доставлено/прочитано», «печатает…», «в сети».
* Свои стикеры: фото из галереи или эмодзи → форма, надпись, масштаб. Долгое нажатие на стикер — удалить.
  Нажатие на чужой стикер → «Сохранить себе».
* Оформление: 6 тем, цвет акцента, фон чата (в т.ч. своя картинка), размер текста. Быстрая смена темы — кнопка 🎨 в чате.
* Настройки: имя, смена пароля, звук, выход.

## Ограничения
* Сообщения приходят, пока приложение открыто. Уведомлений при закрытом приложении нет (для этого нужен Firebase).
* Стикеры хранятся на телефоне (не синхронизируются между устройствами).
* Это учебно-бытовой проект: пароли хранятся в виде хэшей, но шифрования переписки «из конца в конец» нет.

## Запуск для разработки
```
node server/index.js     # http://localhost:3000 — открывается и приложение, и сервер
```
